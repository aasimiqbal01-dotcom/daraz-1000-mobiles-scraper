# Daraz 1000 Mobiles Scraper 📱

Scraped 1000+ mobile products from Daraz.pk using Python, Requests & Pandas.

## What I Did
- Found Daraz's hidden API
- Scraped 25 pages to collect 1000 products
- Extracted Name, Price, Old Price, Rating, Reviews
- Saved data as CSV

## Tools Used
- Python
- Requests
- Pandas
- Google Colab

## Dataset
`daraz_1000_mobiles.csv` - 1000 rows

## How to Run
python scraper.py
